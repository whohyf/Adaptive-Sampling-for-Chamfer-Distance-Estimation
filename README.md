# Adaptive Sampling for Chamfer Distance Estimation

This repository contains the code, canonical experiment outputs, and report
source for a course-scale empirical study of adaptive sampling for Chamfer
distance estimation.

The report studies when a small uniform pilot can choose between:

- fixed-budget uniform sampling,
- importance sampling with a coarse nearest-neighbor proposal, and
- an adaptive rule that routes between the two and may fall back to exact
  computation when the conservative uniform budget reaches `n`.

The canonical results are synthetic and reproducible from the scripts in
`chamfer_project/`. The Text-like row in the report is a synthetic text-like
demonstrator, not a real GloVe/Federalist experiment.

## Setup

Use Python 3.10 or newer.

```bash
pip install -r requirements.txt
```

The core reproducibility path does not download external datasets.

## Quick Validation

```bash
python chamfer_project/exp_adaptive_unit_tests.py
python chamfer_project/exp_validate.py
```

`exp_validate.py` also writes a sample-vs-error figure under
`chamfer_project/figures/`.

## Reproducing the Canonical Results

Run these commands from the repository root:

```bash
python chamfer_project/exp_cv_calibration.py --seed 0
python chamfer_project/exp_pilot_size.py --seed 0
python chamfer_project/exp_threshold_sweep.py --seed 0
python chamfer_project/exp_end_to_end.py --seed 0
python chamfer_project/exp_cost_by_n.py
python chamfer_project/exp_paper_reproduce.py
```

The key report tables and claims use these files:

- `chamfer_project/results/end_to_end_summary.csv`
- `chamfer_project/results/cv_calibration.csv`
- `chamfer_project/results/pilot_size_summary.csv`
- `chamfer_project/results/threshold_sweep_aggregated.csv`
- `chamfer_project/results/threshold_sweep_borderline.csv`
- `chamfer_project/results/cost_by_n.csv`

The most important end-to-end canonical values are:

| Dataset | Uniform error | IS error | Adaptive error | IS cost | Adaptive cost |
|---|---:|---:|---:|---:|---:|
| ShapeNet-like | 0.428 | 0.0118 | 0.0126 | 3604 | 5559 |
| Text-like | 0.00291 | 0.00137 | 0.00337 | 3138 | 50 |
| Outlier | 0.384 | 0.00493 | 0.474 | 2771 | 170 |

Costs are nearest-neighbor-query equivalents. Wall-clock milliseconds are
logged in the CSVs but are not the canonical comparison metric.

## Notes on Interpretation

- The ShapeNet-like end-to-end row uses
  `make_shapenet_pair(high_cv=True)` and has true CV about `3.369`.
- The CrudeNN quality reproduction in Figure 6(b) uses the homogeneous
  point-cloud reproduction setting, `make_shapenet_pair(high_cv=False)`.
- The Outlier row is not a simple adaptive success or failure. The Bernstein
  cost oracle labels the uniform/brute-force side as cheaper at `n=1000`, and
  adaptive follows that side. The realized estimator usually does not trigger
  exact fallback, so the small uniform sample often misses the dominant point.
  This is a missing-mass failure of sample-based uniform estimation, not an
  oracle-routing failure.
